# BELOW

An original, compact first-person megastructure exploration vignette inspired by the four stills in https://x.com/gamesojh/status/2103132027012681993 . Four original painted environments, a walkable progression loop, visual parallax/look, sound cues, and interactive markers. No source image is bundled or copied. No build step, account, server, or spending. Open index.html in a browser.

WASD/arrow keys move; drag to look; E interacts when the marker appears; R restarts. On touch, use the directional buttons and Interact. Move forward in each chamber to its marker, then interact to open the next chamber. The game is a 2D first-person exploration vignette based on four original painted scene layers, not a true 3D continuous level or a GOTY-scale game. Generated background images are original to this project. External fonts and network services are not required.
